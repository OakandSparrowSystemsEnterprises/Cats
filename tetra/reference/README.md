# reference/

Not needed for the build. Two companion archives hold this folder's contents (they were split off to stay under the chat's upload limit):

- `tetra-reference-ruby-and-art.zip`: `ruby/` (Ruby's sketches: Sapphire's West chart, the central island nations, Amethyst's South sketch and continent nations, Obsidian's Far sketch and nations, the notebook page with the deltas (Wetia), the Umbrella Tree Zinnia sketch), `art-versions/` (the four versions of the Canon painting; v4 is `pipeline/art_latest.png`), `tetra_world_spin_original.html` (Joshua's original spinning tetrahedron page, before any of this), `original_spin_page_phone.png`.
- `tetra-reference-screenshots.zip`: `screenshots-v10/` (what version 10 looks like on desktop and phone, plus the six-seam sheet) and `previews/` (marker previews of the three generated maps, the maps sheet, the edge check, the blocky-edge check, the outline preview).

Unzip both into the repo root to restore `reference/` in full.
